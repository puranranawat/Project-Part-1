## Project Report

This repository contains the complete group project for the unit **COIT20246 Networking and Cyber Security**.  
The project is based on the Truelec organisational scenario and addresses all requirements outlined in the Project Specification.

The aim of the project is to design a secure and reliable network, evaluate cloud service options, conduct a cyber security risk assessment, recommend appropriate security controls, analyse ethical and social issues, and reflect on teamwork and project execution. All work has been completed in accordance with industry best practices and the unit marking rubric.

The project report is organised into the following sections:

- [Project Plan](./plan.md)  
  Defines the group communication plan, task allocation, and project schedule.

- [Network Design](./network.md)  
  Documents network assumptions, logical network diagrams, WiFi design, IP addressing plan, redundancy considerations, and recommended network hardware.

- [Cloud Services](./cloud.md)  
  Evaluates cloud virtual machine options using official AWS and Azure pricing calculators, includes cost comparisons, a 5-year cost analysis, and a recommended cloud provider.

- [Security](./security.md)  
  Presents a cyber security risk assessment using the unit template, TVA Matrix screenshots, and detailed security control recommendations for the highest-risk data asset.

- [Ethical Issues](./ethics.md)  
  Discusses ethical, privacy, and legal issues related to data collection, storage, cloud usage, and security, with reference to relevant Australian regulations.

- [Project Reflections](./reflection.md)  
  Reflects on individual and group contributions, GitHub commit history, teamwork effectiveness, challenges encountered, and lessons learned for future projects.

All supporting materials, including network diagrams, cloud pricing exports, risk assessment spreadsheets, screenshots, and images, are included in the repository and linked from the relevant sections. Regular GitHub commits by both group members demonstrate consistent participation and professional project management throughout the term.
